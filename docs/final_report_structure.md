# Final Report Suggested Structure

## 1. Introduction
Introduce phishing, why it is a serious cybersecurity issue, and why machine learning can help.

## 2. Background and Literature Review
Discuss phishing techniques, traditional detection methods, machine learning detection, and awareness training.

## 3. Methodology
Explain dataset collection, preprocessing, feature extraction, selected ML models, and evaluation metrics.

## 4. System Design
Include a workflow diagram showing:
Dataset -> Feature Extraction -> Model Training -> Evaluation -> Results

## 5. Implementation
Describe Python tools, libraries, dataset format, feature extraction code, and model training process.

## 6. Testing and Evaluation
Compare Logistic Regression, Random Forest, Simple Neural Network, and the heuristic baseline using accuracy, precision, recall, and F1 score.

## 7. Awareness Activity
Explain the safe awareness activity and how pre/post scores are compared.

## 8. Ethical, Legal, and Privacy Issues
Discuss consent, safe simulation design, data minimisation, secure data handling, and avoiding real credential collection.

## 9. Conclusion
Summarise the findings and explain which model performed best.

## 10. Future Work
Suggest improvements such as larger datasets, email header analysis, live website feature extraction in a sandbox, and explainable model interpretation.
