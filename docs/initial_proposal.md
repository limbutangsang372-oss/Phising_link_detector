## Proposed Title
Detection and Analysis of Phishing Attacks Using Machine Learning

## Proposed Aim
This project aims to investigate phishing attack detection by applying machine learning techniques to labelled phishing and legitimate datasets. The project will also explore how controlled security awareness activities can help reduce user susceptibility to phishing attacks, while considering ethical, legal, and privacy requirements.

## Proposed Objectives
By the end of this project, I will be able to:

1. Research common phishing attack techniques, detection methods, and machine learning approaches used for phishing detection.
2. Collect and prepare labelled phishing and legitimate data from publicly available datasets such as PhishTank and Kaggle.
3. Extract useful features from phishing and legitimate samples, including URL length, suspicious keywords, domain information, HTTPS/TLS usage, HTML content features, and email header characteristics.
4. Train and evaluate machine learning models such as Logistic Regression, Random Forest, and a simple Neural Network for phishing detection.
5. Compare the performance of machine learning models against basic rule-based or heuristic phishing detection methods.
6. Design a controlled and ethically approved phishing awareness activity using safe simulated examples in a lab-based or consenting participant environment.
7. Analyse whether a short awareness intervention improves users’ ability to identify phishing attempts.
8. Discuss the ethical, legal, and privacy considerations involved in phishing detection, phishing simulations, and data handling.

## Draft Rationale
Phishing is one of the most common and serious cybersecurity threats faced by individuals and organisations. Attackers use fake emails, malicious links, and fraudulent websites to trick users into revealing sensitive information or performing unsafe actions. These attacks can result in financial loss, identity theft, data breaches, and damage to an organisation’s reputation.

Although many organisations provide security awareness training, phishing attacks continue to evolve and remain difficult to detect. Traditional rule-based detection methods may not always identify new or modified phishing attempts, especially when attackers use more advanced social engineering techniques. At the same time, users can still fall victim to convincing phishing messages even after receiving training.

Machine learning provides a useful approach for improving phishing detection because it can identify patterns in URLs, emails, website content, and metadata. By training models on labelled phishing and legitimate datasets, it may be possible to detect phishing attempts more accurately than simple rule-based methods.

This project is important because it combines technical phishing detection using machine learning with an investigation into human awareness. By comparing different machine learning models and considering user-focused awareness activities, the project will provide a better understanding of how both automated detection and user education can support phishing defence.
